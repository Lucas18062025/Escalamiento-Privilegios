🗺️ Ruta de Aprendizaje Recomendada
Sigue esta ruta paso a paso para dominar el escalamiento de privilegios, desde principiante hasta avanzado.
1
Fundamentos de Linux
Domina permisos, usuarios, grupos, SUID, sudo. Practica con Linux PrivEsc (TryHackMe) y máquinas fáciles de VulnHub.
2
Fundamentos de Windows
Aprende privilegios de Windows, tokens, servicios. Practica con Windows PrivEsc (TryHackMe) y Blue (HTB).
3
Enumeración Automática
Usa LinPEAS y WinPEAS. Entiende qué buscan y por qué. No dependas ciegamente de scripts.
4
Técnicas Avanzadas Linux
Kernel exploits, capabilities, Docker escape, LD_PRELOAD. Máquinas HTB medium como Lame, SwagShop.
5
Técnicas Avanzadas Windows
Token impersonation, AD abuse, GPO misconfig. Máquinas HTB medium/hard como Active, Sauna.
6
Active Directory
Pivoting, lateral movement, BloodHound, impacket. Pro Labs de HTB o TryHackMe AD paths.
7
Certificaciones
Considera OSCP, eJPT, PNPT, CRTP. Son prácticas y validan tu progreso.

🏴‍☠️ HackTheBox — Máquinas Recomendadas
Máquinas reales, sin guías. Ideal para practicar metodología propia.
Lame
Easy
Samba + distcc. Escalamiento vía sudo exploit clásico. Perfecta para empezar.
Linux Easy OSCP-like
Blue
Easy
EternalBlue (MS17-010). Escalamiento directo a SYSTEM. Clásica de Windows.
Windows Easy OSCP-like
SwagShop
Easy
Magento exploit → shell → escalamiento vía sudo. Buena práctica de enumeración web + privesc.
Linux Easy Web → PrivEsc
Bastion
Easy
Windows con VHD montable. Escalamiento vía SAM hashes. Creativa y educativa.
Windows Easy OSCP-like
Active
Medium
Active Directory completo. Kerberoasting, AS-REP Roasting, DCSync. Escencial para AD.
Windows AD Medium
Sauna
Easy
AD con AS-REP Roasting. Escalamiento vía DCSync. Excelente para practicar impacket.
Windows AD Easy

📜 Certificaciones Recomendadas
Valida tu progreso con certificaciones prácticas reconocidas en la industria.
  • eJPT — eLearnSecurity Junior Penetration Tester. Entrada, práctico, económico.
  • PNPT — Practical Network Penetration Tester. 100% práctico, reporte real.
  • OSCP — Offensive Security Certified Professional. El estándar de la industria.
  • CRTP — Certified Red Team Professional. Especializado en Active Directory.
  • eCPPTv3 — eLearnSecurity Certified Professional Penetration Tester. Más completo que eJPT.
